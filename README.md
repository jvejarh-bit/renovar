## Privacidad

Los registros se guardan solo en el teléfono de cada persona. No pasan por ningún servidor: este sitio solo entrega la app.

## Actualizar

Al cambiar cualquier archivo, sube el número de versión en `sw.js` (por ejemplo `renovar-v2` → `renovar-v3`) para que los teléfonos reciban la versión nueva.
