# Registro de Diálogo Interno

Lleva tu registro en cuatro simples pasos:

1. La situación.
2. El pensamiento que apareció.
3. Lo que dice la Palabra.
4. El pensamiento verdadero con que se reemplaza.

Después marca cada vez que el pensamiento vuelve y envía sus registros a su consejero antes de la sesión (Romanos 12:2; 2 Corintios 10:5).

**Abrir la app:** https://jvejarh-bit.github.io/renovar/

## Instalar en el iPhone

1. Abre el enlace.
2. Toca el botón Compartir (en algunas versiones está dentro del botón «···»).
3. Elige «Agregar a pantalla de inicio» y luego «Agregar».

## Privacidad

Los registros se guardan solo en el teléfono de cada persona. No pasan por ningún servidor: este sitio solo entrega la app.

## Actualizar

Al cambiar cualquier archivo, sube el número de versión en `sw.js` (`renovar-v1` → `renovar-v2`) para que los teléfonos reciban la versión nueva.
